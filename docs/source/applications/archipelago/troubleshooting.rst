-------------------------------------
Bug: Disappearing Canvases in Mirador
-------------------------------------

When using Mirador as a viewer, users sometimes report that clicking the thumbnail of the canvas they are on currently
makes all canvases disappear until page reload.

This is a bug related to Mirador 3.3.  To address, the display settings just need to be updated to Mirador 4.0.
