============================
Migrating Fedora Collections
============================

Clone `charon-crossing <https://github.com/tamulib-dc-labs/charon-crossing>`_ repository.

Follow documentation on charon-crossing README. Results should be AMI sets that need some cleanup before ingesting into Archipelago.

Make sure you are not uploading tifs into Archipelago. If a Fedora collection contains tifs, you will need to download the files and then convert to jp2s.
